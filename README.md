# カラオケ歌詞タイミング同期エディター

歌詞テキストを1行ずつ入力し、各行にタイムスタンプ（MM:SS.xx形式）を設定することで、カラオケ風プレビューとLRC形式ファイルの書き出しができるエディターです。再生シミュレーション機能で現在行がピンクにハイライト表示されます。LRCファイルのインポートにも対応しています。

## 機能
- 歌詞テキストの1行ずつ入力と読み込み
- 各行へのタイムスタンプ（MM:SS.xx）手動入力
- 等間隔自動タイムスタンプ調整
- カラオケ風プレビュー（現在行ハイライト・次行表示）
- 再生・一時停止・停止・シークバー操作
- プレビュー文字サイズ調整（小/中/大/特大）
- LRC形式ファイルのダウンロード書き出し
- LRC形式テキストのインポート
- 楽曲メタデータ（タイトル・アーティスト）設定
- キーボードショートカット（スペース: 再生/一時停止、S: 停止）
